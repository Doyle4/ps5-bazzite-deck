## Updating from an earlier version (v1.0.3 or newer, no reflash)
On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection (a USB tether from a phone works if Wi-Fi doesn't):
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh)
```
It downloads the latest release, checks it, makes a backup, installs the new kernel, drivers and settings, and prints `DONE` plus an undo command. Then power off and run the loader as usual.

**From v1.0.2 or older:** reflash.
