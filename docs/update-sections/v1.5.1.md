## Updating
From v1.0.3 or newer, without reflashing.
On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection. While v1.5.1 is a pre-release, the generic command installs the latest stable release; use the exact one:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.5.1/ps5-bazzite-deck-v1.5.1-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.5.1/ps5-bazzite-deck-v1.5.1-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.5.1-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.5.1-update.tar.xz && bash ps5-bazzite-deck-v1.5.1-update/update.sh
```
It checks the download, makes a backup, installs the new kernel, drivers and settings, and prints `DONE` plus an undo command. Then power off and start with the loader. The generic command for later: `bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh)`.

**From v1.0.2 or older:** reflash.
