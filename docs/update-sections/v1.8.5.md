## Updating
A kernel update for consoles on **v1.8.4** (update to v1.8.4 first with the normal update command if you're on something older). On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && rm -rf ps5-quick-v1.8.5* && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.8.5/ps5-quick-v1.8.5.tar.gz && tar xzf ps5-quick-v1.8.5.tar.gz && bash ps5-quick-v1.8.5/install.sh
```
It keeps a backup and prints an undo line. Then power off and start with the loader. `/etc/ps5-bazzite-deck-version` then says `v1.8.5 (quick kernel)`.
