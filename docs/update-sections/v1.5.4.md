## Updating
A kernel update for consoles on **v1.5.1 or v1.5.2** (update to v1.5.2 first if you're on something older). On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && rm -rf ps5-quick-v1.5.4* && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.5.4/ps5-quick-v1.5.4.tar.gz && tar xzf ps5-quick-v1.5.4.tar.gz && bash ps5-quick-v1.5.4/install.sh
```
It keeps a backup and prints an undo line. Then power off and start with the loader. `/etc/ps5-bazzite-deck-version` keeps showing your previous version; `uname -v` shows the new kernel's build time.
