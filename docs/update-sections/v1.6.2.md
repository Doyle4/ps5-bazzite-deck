## Updating
A kernel update for consoles on **v1.6.0 or v1.6.1** (update to v1.6.0 first with the normal update command if you're on something older). On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && rm -rf ps5-quick-v1.6.2* && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.6.2/ps5-quick-v1.6.2.tar.gz && tar xzf ps5-quick-v1.6.2.tar.gz && bash ps5-quick-v1.6.2/install.sh
```
It keeps a backup and prints an undo line. Then power off and start with the loader. `/etc/ps5-bazzite-deck-version` then says `v1.6.2 (quick kernel)`.
