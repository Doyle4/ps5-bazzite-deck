## Updating
From v1.0.3 or newer, without reflashing. This is an update only; for a fresh install, flash the latest release's image first and then run this. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.5.2/ps5-bazzite-deck-v1.5.2-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.5.2/ps5-bazzite-deck-v1.5.2-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.5.2-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.5.2-update.tar.xz && bash ps5-bazzite-deck-v1.5.2-update/update.sh
```
It checks the download, makes a backup, installs the new kernel, drivers and settings, and prints `DONE` plus an undo command. Then power off and start with the loader. The normal update command installs the latest release, not this pre-release.
