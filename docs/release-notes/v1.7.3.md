## What's new
- **Less VRR flicker on OLED TVs:** VRR no longer goes below 48 Hz (the PS5 system's own floor; many TVs allow 40 Hz, where OLEDs flicker when the refresh rate swings). Below 48 fps, frames are shown twice at 120 Hz modes; at 60 Hz modes the refresh stays at 60 Hz. Thanks to hsgodd for the suggestion.

## Known issues
- **VRR on consoles with the VERDE HDMI chip** isn't supported yet, so it isn't offered there (nor is 4K120).
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on:** switching Deep Colour off fixes it for now.
- **Sleep uses a lot of power** (the GPU stays on). For longer breaks, power off.
