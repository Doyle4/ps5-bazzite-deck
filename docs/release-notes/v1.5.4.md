## What's new
- **VRR test 24:** the two messages Sony's system sends when switching VRR on that ours didn't (found by hsgodd's full capture of the stock sequence). Only active with ` hdmi.vrr_test=1` and the chip's own VRR mode; nothing changes otherwise.

## VRR test
For **FLAVA3** consoles with ` hdmi.vrr_test=1` in `cmdline.txt` and a TV with VRR. hsgodd captured Sony's complete VRR switch: its VRR settings match ours, but two InfoFrames come first that we never sent. This build sends them in the chip's own VRR mode. All switches work at runtime (`P=/sys/module/hdmi/parameters`), then **VRR off and on again in the game** so they apply.

**Before each step:** a fullscreen game limited to **60 fps**, HDR off, `echo 1 | sudo tee $P/vrr_chip`.

1. **24a: SPD + DRM InfoFrame.** `echo 87011a5c0200000000000000000000000000000000000000000000000000 | sudo tee $P/vrr_drm` (stock's DRM InfoFrame; hsgodd, use the exact bytes and length from your capture), VRR off/on, wait a minute. Picture? TV says VRR?
2. **24b: also no FreeSync packet** (stock sends none, and ours shares the DRM InfoFrame's slot): `echo 0 | sudo tee $P/vrr_vsif`, VRR off/on, wait a minute.
3. **SPD alone:** `echo | sudo tee $P/vrr_drm` (empty), VRR off/on.

**Report:** `vrr-report` after each step; the log lines `VRR DRM InfoFrame at 0x7e40` and `VRR SPD` show what went out. Post the files in #bazzite-prereleases-experimental with the step number. With ` hdmi.icc_trace=1` switched on during the VRR switch, the full message trace can be lined up against the stock capture.

**No picture after VRR goes on?** Switch VRR off over SSH (it comes back within about a minute): `ssh -t ps5@<PS5 IP> 'export XDG_RUNTIME_DIR=/run/user/$(id -u) GAMESCOPE_WAYLAND_DISPLAY=gamescope-0; gamescopectl adaptive_sync 0'` (`adaptive_sync 1` switches it on again).

**Switch off:** remove ` hdmi.vrr_test=1` from `cmdline.txt` and start cold.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): Game Mode's X window thread (`gamescope-xwm`) triggers them, the graphics queue times out and is reset, and the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on** (the desktop is fine): switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back**, while Wi-Fi itself stays at full speed. A cold start brings the speed back.
