## What's new
- **VRR works at 4K60 and 1080p120** on consoles with the FLAVA3 HDMI chip, still as an experiment you switch on: Lawson's fix (v1.6.1's test 28) gave real VRR on an LG C4, the TV's FreeSync following the game. With ` hdmi.vrr_test=1` in `cmdline.txt`, it's now simply Steam's VRR setting.
- **At 1440p VRR stays off** instead of the picture going black: that mode can't be carried yet. The refresh stays fixed there.

## VRR test
For **FLAVA3** consoles (`ps5-report` shows it) with a TV that supports VRR or FreeSync.
1. Add ` hdmi.vrr_test=1` to the end of `cmdline.txt`, power off, start with the loader.
2. Game Mode: **4K60 or 1080p120**, HDR off, then Settings → Display → **Enable VRR**.
3. In a game, lower the frame limit (quick access → Performance) and watch the TV's VRR or FreeSync info: the refresh should follow the game. After switching VRR on, or changing the mode, the HDMI chip takes a few seconds to switch over.

**Expected:** at 4K60 the range is 40–60 Hz; below 40 fps it goes back to 60 Hz (frames can't be doubled within 40–60). At 1080p120 frame doubling works below 40 fps.

**To try 1440p anyway:** `echo 1 | sudo tee /sys/module/hdmi/parameters/vrr_any_mode`, then VRR off and on. It has given a black screen so far.

**Report:** `vrr-report`, in #bazzite-prereleases-experimental; the log line `PS5 VRR: timing SDP …` shows the packet for your mode.

**No picture?** Over SSH: `export XDG_RUNTIME_DIR=/run/user/$(id -u) GAMESCOPE_WAYLAND_DISPLAY=gamescope-0; gamescopectl adaptive_sync 0` (the picture comes back within about a minute), or switch VRR off in Steam blind. A cold start without ` hdmi.vrr_test=1` always works.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on:** switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back.** A cold start brings the speed back.
