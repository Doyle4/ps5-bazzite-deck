Everything from v1.5.0, plus:

## What's new
- **Updates always end in a cold start,** also with warm reboot switched on: the restart after an update now goes through the PS5 system, so a new kernel always starts on freshly reset hardware.
- **The fan follows the console's own target again** (80 °C on the consoles we've seen). v1.5.0 set 85 °C, which made the fan start later. CPU boost stays on; `FAN_TARGET=` in `/etc/ps5-bazzite-deck/perf.conf` still sets a target if you want one.
- **A shorter `cmdline.txt`:** two options we used to add are built into the kernel now, and the update removes exactly those two from the line. Anything you added yourself stays.
- **`ps5-report` built in:** one command that saves your hardware and the relevant logs in a file for bug reports, also without network. `vrr-report` does the same for VRR tests.
- **VRR as an experiment in the kernel,** off unless you switch it on (see VRR test below). Without the option nothing changes.

## VRR test
VRR doesn't work yet; this is for testers with an original PS5 or Slim with the **FLAVA3** HDMI chip (`ps5-report` shows it) and a TV with VRR. It contains the whole test series so far (up to test 20): the chip's own VRR mode with Sony's setup sequence, and the setup re-applied every time the TV re-announces itself.

**Switch on:** add ` hdmi.vrr_test=1` to the end of `cmdline.txt` (one line), power off and start with the loader.

**Test** (same steps every time, so results compare):
1. **TV:** VRR on for that HDMI input (LG: "VRR & G-Sync" and "AMD FreeSync Premium"; Samsung: Game Mode + FreeSync; Sony: VRR in the input settings).
2. **Game Mode:** HDR off. Pick one mode and note it (4K60, 1440p120 or 1080p120).
3. Start a fullscreen game, limit it to **60 fps** (quick access menu → Performance), and switch **VRR on**.
4. Watch for a minute: picture, black, no signal, flicker, rolling? What does the TV show (VRR indicator, refresh rate)?
5. **The chip's own VRR mode** (the main test): `echo 1 | sudo tee /sys/module/hdmi/parameters/vrr_chip`, then VRR off and on again in the game, and watch again.

**Report:** right after each test, in the same boot, run `vrr-report`. It asks four short questions and saves one file with the kernel's VRR log; post the file in #bazzite-prereleases-experimental with the step number, one post per test. Newer VRR tests come as separate `vrr-test` releases with their own notes.

**Switch off:** remove ` hdmi.vrr_test=1` from `cmdline.txt` and start cold.

## Known issues
- **Colours too dark, shadows crushed, on TVs whose RGB range / black level is on "Auto"** (most current TVs): the PS5 told the TV "limited range" by mistake. Fixed in v1.5.3. Until then, set the TV's black level / RGB range for that input to **High / Full**, or add ` hdmi.rgb_range=0` to `cmdline.txt` (remove it again after updating to v1.5.3).
- **GPU page faults when Game Mode starts** (coming from the desktop): Game Mode's X window thread (`gamescope-xwm`) triggers them, the graphics queue times out and is reset, and the screen can freeze for a while. Being investigated; `ps5-report` output helps.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on** (the desktop is fine): switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back**, while Wi-Fi itself stays at full speed; being looked at. A cold start brings the speed back.
- VRR isn't usable yet.
