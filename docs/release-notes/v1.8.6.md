## What's new
- **No more blanking with VRR on FreeSync-only monitors:** VRR is offered only to displays with HDMI VRR, as on the PS5 system. Monitors that only announce FreeSync blanked on every refresh change; they now run without VRR. TVs with HDMI VRR keep it.

## Testing
FreeSync-only monitors: no "Enable VRR" any more, and no blanking; `sudo dmesg | grep "PS5 VRR"` says `not available (the display announces only FreeSync, no HDMI VRR)`. TVs with HDMI VRR: VRR works as before (`PS5 VRR: available … (HDMI VRR range)`).

## Known issues
- **VRR on monitors with only FreeSync** isn't supported (the PS5 system doesn't support it either).
- **VRR and 4K120 on consoles with the VERDE HDMI chip** aren't supported yet, so they aren't offered there.
- **PS5 Pro:** a first version; tell us in #bazzite-ps5-pro-tests what works.
