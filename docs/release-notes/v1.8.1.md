## What's new
- **Fix: no picture at 4K120 on some TVs since v1.8.0:** the TV's automatic game mode signal (ALLM) is gone again; it disturbed the 4K120 link setup. Linux on a PC doesn't send it either.
- **VRR switches like on a PC:** switching VRR on or off (Steam's setting, or Steam's menus doing it) no longer blanks the screen for about 2 seconds. The HDMI chip switches in one go, without setting the picture up again. Changing the resolution still takes a moment, as on any display.

## Testing
4K120: pick 3840x2160 at 120 Hz; the picture should come up as on v1.7.x. With VRR on in Steam: open and close the quick access menu and Steam's main menu during a game; the picture should stay, and the TV keep showing VRR/FreeSync. Then switch VRR off and on in Settings → Display at 4K60 and at a 120 Hz mode. Report your TV model either way, with `sudo dmesg | grep -e "VRR: on" -e "VRR: off"`.

## Known issues
- **PS5 Pro:** first build (v1.8.0), untested on a Pro; tell us what works and what doesn't.
- **VRR, 4K120 and ALLM on consoles with the VERDE HDMI chip** aren't supported yet, so they aren't offered there.
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Sleep uses a lot of power** (the GPU stays on). For longer breaks, power off.
