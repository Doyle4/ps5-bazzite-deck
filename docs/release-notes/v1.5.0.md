**Pre-release, for testing.** Everything from v1.4.1, plus:

## What's new
- **USB-C DisplayPort output:** the console's front USB-C port drives displays, and the **PSVR2** without an adapter (ps5-linux-patches #57 by **tertiumndatur**, thanks **rmux**; ported to our 7.3 kernel). For the PSVR2 you also need userspace that isn't in the image yet: [PSVR2Toolkit](https://github.com/BnuuySolutions/PSVR2Toolkit), and for reprojection a [patched Mesa](https://github.com/DryhoppedIPA/bc250-gfx1013-fix/blob/main/patches/mesa/0001-gfx1013-compute-queue-fix.patch). Upstream tested this on fat consoles only; reports from slims are very welcome.
- **CPU boost and fan:** the CPU may boost up to 3.5 GHz under load (it still idles down), and the fan aims for 85 °C. `ps5-perf status` shows it, `ps5-perf off` returns to the console's own behaviour.
- **Better colours at 1080p and 4K60** on TVs that showed crushed blacks or oversaturated colours there but not at 1440p.
- **Fixes the likely cause of "generic display" with games stuck at 1080p** after going from the desktop back to Game Mode: broken display announcements from the HDMI chip no longer wipe the display's details.
- **Warm reboot (optional, `ps5-warm-reboot on`):** on IW620 consoles Bluetooth now comes back after a warm restart too, not just Wi-Fi.
- **Verde consoles:** TVs now get the "game" content type, so they switch to their low-latency mode like on other PS5s.
- **Wi-Fi stays fast:** power saving is kept off even if Steam's developer settings turn it back on.
- **First start explains itself:** the blank screen with the blinking cursor now says that Steam is setting itself up (this can take several minutes after joining Wi-Fi) and not to power off. Powering off there was the most common reason for a broken first start (thanks kishy, ObsessiveRug).
- **Fewer hangs when switching between Game Mode and the desktop** (minutes on the blinking cursor). Two causes are fixed: a closing session could leave stale GPU address mappings behind (GPU page faults, then a stuck graphics queue; the GPU's TLB flushes no longer go through the KIQ, from PR #57), and the HDMI code blanked the console during the switch. If it still happens to you, the log line under known issues helps.
- **From the same PR:** a 1 ms poll on the Salina USB controller (for DualSense), faster Ethernet receive, non-blocking Bluetooth HID frames, and sturdier HDMI EDID handling.

## Known issues
- **If you use warm reboot (`ps5-warm-reboot on`): after installing this update, power off and start with the loader instead of restarting.** A restart would go straight into the new kernel without the PS5 resetting its hardware, which can hang. From the next version the updater takes care of that itself.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on** (the desktop is fine): switching Deep Colour off fixes it for now; being looked at.
- **Steam downloads can get slower after switching to the desktop and back**, while Wi-Fi itself stays at full speed; being looked at. A cold start brings the speed back.
- VRR isn't in a release yet; it continues in the vrr-test builds.
- If switching between Game Mode and the desktop still hangs, or a display shows up as "generic" with 1080p only afterwards, send `journalctl -b -k --no-pager | grep -e "got real edid" -e "EDID announcement" -e "PS5 display route" -e "modes:" | tail -20`.
