## What's new
- **Test build: 4K at 120 Hz** on consoles with the FLAVA3 HDMI chip and an HDMI 2.1 TV, over the TV's FRL link (Lawson's work, following Sony's own setup for this mode). Off unless switched on; see below.

## 4K120 test
For **FLAVA3** consoles with an HDMI 2.1 TV that supports 4K120 (and an HDMI cable rated for it).
1. Add ` hdmi.frl_4k120=1` to the end of `cmdline.txt`, power off, start with the loader.
2. Game Mode: Settings → Display → resolution **3840x2160**, refresh rate **120**.
3. Check the TV's info screen: 4K, 120 Hz. Between the GPU and the HDMI chip the picture runs as YCbCr 4:2:2 (the link can't carry 4K120 RGB); the TV still gets 4K120.
4. VRR on top: Steam's VRR setting, as at other resolutions.

**Report:** `sudo dmesg | grep -e "over FRL" -e "PS5 VRR"` and what the TV shows, in #bazzite-prereleases-experimental. If 4K120 isn't offered at all, include `ps5-report`.

**No picture at 4K120?** Wait a minute, then switch back to 4K60 blind or over SSH; or remove ` hdmi.frl_4k120=1` and start cold.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on:** switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back.** A cold start brings the speed back.
