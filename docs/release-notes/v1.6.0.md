## What's new
- **Colours fixed on TVs set to "Auto":** since v1.5.0 the PS5 told the TV "limited range" by mistake while sending full-range colours, so on most current TVs the picture was too dark with crushed shadows, at every resolution. If you worked around it (the TV's black level set by hand, or `hdmi.rgb_range` in `cmdline.txt`), you can set the TV back to Auto and remove the option.
- **The "Steam is setting itself up" message is gone:** it didn't show, or only for a moment. The update removes it from existing installs. Steam still updates itself in the background on the first start; don't power off then.
- **VRR is still an experiment, off by default** (` hdmi.vrr_test=1`). It now includes the research tools from the v1.5.2–v1.5.6 test builds.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): Game Mode's X window thread (`gamescope-xwm`) triggers them, the graphics queue times out and is reset, and the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on** (the desktop is fine): switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back**, while Wi-Fi itself stays at full speed. A cold start brings the speed back.
- One report of Bluetooth problems and not getting back to Game Mode from the desktop on v1.5.1 is being looked at. If it happens to you, run `ps5-report` right afterwards and post the file in Discord.
