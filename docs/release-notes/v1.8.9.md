## What's new
> **TEST BUILD** for 4K120; everyone else stays on the release marked **Latest**.

- **Fix: black screen loop at 4K120** when switching between Game Mode and the desktop (seen on an LG OLED): the TV re-announces itself while it sets up the 4K120 link, and the console used to answer that by setting up 4K120 again, over and over. It doesn't any more; if the 4K120 link really doesn't come up, the console falls back to 4K by itself (since v1.8.5).

## Testing
At 4K120 (VRR and HDR as you use them), switch between Game Mode and the desktop a few times. Then post `sudo dmesg | grep -e 4K120 -e re-arm -e "falling back" -e "page fault"` and your TV model.
