## What's new
> **TEST BUILD** for 4K120; everyone else stays on the release marked **Latest**.

- **4K120 sent as YCbCr 4:2:2 at 8 bits** instead of RGB at 6 bits, the format the HDMI chip's 4K120 setup is made for. A test for the GPU fault (`gamescope-xwm` page faults, black screen) some see when switching between Game Mode and the desktop at 4K120. It also removes the colour banding 6 bits can cause.

## Testing
At 4K120, switch between Game Mode and the desktop several times. Then: `sudo dmesg | grep -e "over FRL" -e "page fault" -e 4K120`. The first line should say `YCbCr 4:2:2, 8 bpc`. Post it with your TV model, and whether colours look right.
