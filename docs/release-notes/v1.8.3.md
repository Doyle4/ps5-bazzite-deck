## What's new
> **PRO ONLY.** A test build for the PS5 Pro. On an original PS5 or a Slim, stay on the release marked **Latest**; the fixes in here come to every model with the next full release.

- **Test build for 4K120:** on some TVs 4K120 has given no picture since v1.8 with VRR on. With VRR on, the HDMI chip now switches to VRR only once the 4K120 link has had time to come up; 4K120 is offered only at 120.00 Hz (not 119.88), which is what the HDMI chip's setup is made for.

## Testing
At 3840x2160, 120 Hz, with VRR on and with VRR off: picture? Then `sudo dmesg | grep -e "over FRL" -e "VRR: on"` and your TV model, in #bazzite-prereleases-experimental.

## Known issues
- **PS5 Pro:** first build (v1.8.0), untested on a Pro; tell us what works and what doesn't.
- **VRR and 4K120 on consoles with the VERDE HDMI chip** aren't supported yet, so they aren't offered there.
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
