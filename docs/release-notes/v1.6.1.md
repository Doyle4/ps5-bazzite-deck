## What's new
- **The USB-C port's DisplayPort output is off by default:** switching it on can reset a device on the front USB-C port, such as a boot drive there. For a USB-C display or the PSVR2, add ` usbc_dp.enable=1` to `cmdline.txt`.
- **VRR test 28, based on Lawson's work:** the piece our VRR attempts were missing (a timing packet the GPU sends to the HDMI chip every frame), plus the chip's follow mode. Off unless switched on; see below.

## VRR test
For **FLAVA3** consoles with a TV with VRR, ported from Lawson's PS5 VRR work, which gives real VRR on his setup (the TV's FreeSync indicator following the game at 40–60 Hz).

**Setup:** ` hdmi.vrr_test=1` in `cmdline.txt`, cold start. In Game Mode: VRR **off** in Settings → Display (so a black screen can't lock you out), HDR off, a fullscreen game limited to 60 fps, then:
```
P=/sys/module/hdmi/parameters; echo 2 | sudo tee $P/vrr_chip
```
Switch VRR on over SSH and wait about 10 seconds (the chip is switched to follow mode step by step, one step per second):
`ssh -t ps5@<PS5 IP> 'export XDG_RUNTIME_DIR=/run/user/$(id -u) GAMESCOPE_WAYLAND_DISPLAY=gamescope-0; gamescopectl adaptive_sync 1'`

**What to look for:** a stable picture, the TV reporting FreeSync/VRR, and its refresh rate following the game (lower the frame limit to 45 to see it move). The log shows `VRR follow:` lines for each step.

**Variants:** `echo 0 | sudo tee $P/vrr_vsif` (no FreeSync packet in the HDR slot, only the one in the SPD slot); `echo 2 | sudo tee $P/vrr_timing_sdp` (timing and FreeSync packets both).

**Report:** `vrr-report`, posted in #bazzite-prereleases-experimental. **No picture?** `gamescopectl adaptive_sync 0` over SSH (as above, with `0`); the picture comes back within about a minute.

**Switch off:** remove ` hdmi.vrr_test=1` and start cold.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on:** switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back.** A cold start brings the speed back.
