Everything from v1.5.2, plus:

## What's new
- **Colours fixed on TVs set to "Auto":** since v1.5.0 the PS5 told the TV "limited range" by mistake, while sending full-range colours, so on most current TVs (those that follow that flag, e.g. LG) the picture was too dark with crushed shadows, at every resolution. Now the TV is told "full range", as intended. If you worked around it by setting your TV's black level / RGB range by hand, or with `hdmi.rgb_range` in `cmdline.txt`, you can set the TV back to Auto and remove the option.

- **VRR research: a full ICC trace,** off unless switched on (see VRR test below).

## VRR test
Test 21 answered the big question: the GPU really does vary the frame length, and the stock PS5 system gets real VRR through the same HDMI chip, so what's missing is how the chip is programmed. This build can log every message Linux sends to the chip, to compare with the stock system's messages. For **FLAVA3** consoles with ` hdmi.vrr_test=1` in `cmdline.txt`:
1. In Game Mode, a fullscreen game at 60 fps, VRR off.
2. `echo 1 | sudo tee /sys/module/hdmi/parameters/vrr_chip; echo 1 | sudo tee /sys/module/hdmi/parameters/icc_trace`
3. Switch VRR on in the game, wait 10 seconds, switch it off again.
4. `echo 0 | sudo tee /sys/module/hdmi/parameters/icc_trace; sudo dmesg | grep "ICC " > ~/icc-trace.txt`
5. Post `icc-trace.txt` in #bazzite-prereleases-experimental.

## Known issues
- **GPU page faults when Game Mode starts** (coming from the desktop): Game Mode's X window thread (`gamescope-xwm`) triggers them, the graphics queue times out and is reset, and the screen can freeze for a while. Being investigated.
- **Garbled picture in Game Mode on some older LG TVs with "HDMI Ultra Deep Colour" on** (the desktop is fine): switching Deep Colour off fixes it for now.
- **Steam downloads can get slower after switching to the desktop and back**, while Wi-Fi itself stays at full speed. A cold start brings the speed back.
